# RMC Kiosk Scanner — download

Install the RMC attendance kiosk app on an Android tablet:

**[Download the latest APK](https://github.com/paradox-maker/rmc-kiosk-download/releases/latest/download/rmc-kiosk.apk)**

1. Open the link above on the tablet (Chrome).
2. Allow Chrome to install apps when Android asks.
3. Open the app — an RMC admin must approve the new tablet before it can scan.

Installed tablets update themselves automatically; reinstall only when told to.
